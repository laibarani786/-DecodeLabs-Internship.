# Rule-Based Chatbot 🤖

## Project Description
This project is a simple Rule-Based Chatbot created using Python.  
The chatbot responds to predefined user inputs using if-else conditions.

It can:
- Respond to greetings
- Answer simple questions
- Handle basic conversation
- Exit when the user types bye, exit, or quit

---

## Features
- Greeting responses
- Question answering
- Continuous chatting using loop
- Exit command handling
- Simple AI chatbot concept

---

## Technologies Used
- Python
- If-Else Statements
- While Loop
- String Handling

---

## How the Chatbot Works
The chatbot takes input from the user and checks the message using if-else conditions.

Example:
- If the user types "hello"
  - The chatbot replies: "Hello! Nice to talk with you."

- If the user types "how are you"
  - The chatbot replies: "I am doing great."

- If the user types "bye"
  - The chatbot exits the program.

The chatbot runs continuously inside a `while True` loop until the user exits.
